1. Función de Transferencia (Proceso Integrador)

El control de nivel mediante bombas peristálticas se modela como un proceso integrador de primer orden con tiempo muerto. A diferencia de las válvulas de control (procesos autorregulados), el tanque no alcanza el estado estacionario sin intervención del controlador.

$$ G_p(s) = \frac{Y(s)}{U(s)} = \frac{k}{\tau_1 s + 1} e^{-\theta s} $$
  • \( k \): Ganancia del proceso (calculada mediante \(\Delta y / (\Delta t \cdot \Delta u)\)).
  • \( \theta \): Tiempo de retardo (\(t\) hasta que el nivel responde al cambio de la bomba).
  • \( \tau_1 \): Constante de tiempo del proceso integrador.

2. Ecuación de Control Híbrido (Feedback + Feedforward)

Para contrarrestar los disturbios encadenados (\(\Delta Q_d\)) en el banco de flotación, se implementa un algoritmo PI estándar apoyado por un elemento Feedforward pre-alimentado, donde el caudal de entrada actúa como perturbación medible.

$$ u_i(t) = K_{c_i} \left( e_i(t) + \frac{1}{\tau_{i}} \int_{0}^{t} e_i(\tau)d\tau \right) + K_{ff_i} \Delta Q_{d_i} $$
$$ \text{Donde } \Delta Q_{d_i} = Q_{d_i}(t) - Q_{d_i}(t-1) \text{ para } i = 1,2,3. $$

3. Reglas de Sintonización SIMC

La calibración del controlador Proporcional-Integral se rigió por las reglas SIMC (Simple Internal Model Control) para procesos integradores puros, garantizando que el sistema sea inmune a oscilaciones lentas y rechace las perturbaciones.

$$ K_c = \frac{1}{k'} \frac{1}{\tau_c + \theta} $$
$$ \tau_i = \min\{\tau_1, 4(\tau_c + \theta)\} $$

1. Arquitectura de Control PLC (General Electric)

El control físico de las bombas y lectura de nivel óptico se llevó a cabo utilizando un sistema PLC conectado mediante GEHCS I/O Server a MATLAB.

  • Software: Proficy Machine Edition 7.0
  • Módulo Sensores (Input): IC693ALG223 (Direcciones AI00X)
  • Módulo Actuadores (Output): IC693ALG392 (Direcciones AQ00X)
// Flujo de Comunicación DDE (Dynamic Data Exchange)
channel = ddeinit('GEHCS', 'PLC');

// Lectura de Sensores Ópticos (Nivel)
bits_sensor = ddereq(channel, 'AI001');

// Escritura en Bombas Peristálticas
ddepoke(channel, 'AQ001', bits_actuador);

2. Programación Ladder y Cuantización a 16-bit

Las señales en los canales (terminals) operan en lazos de corriente estándar de 4-20 mA, convertidos digitalmente a datos tipo INT (Entero de 16-bit). En la lógica Ladder, se utilizaron bloques MOVE_INT para vincular los registros lógicos con las salidas físicas.
